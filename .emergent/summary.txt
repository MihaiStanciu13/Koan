<product_requirements>
The goal is to build Koan, a production-ready mobile and web app designed for corporate professionals. The app's core purpose is to reduce work friction and burnout through subtle, well-timed behavioral nudges, avoiding metrics and dashboards.

Key Features:
- **Smart Triggers:** Nudges based on phone usage (inactivity, app switching) and integrated work tools (Outlook, Slack, Gmail, etc.).
- **Nudge System:** Gentle notifications with optional Why this nudge? explanations. An AI-powered engine generates these nudges.
- **User Modes:** Micro-modes (Focus, Meeting) and a low-frequency Whisper Mode.
- **Core Loop:** A user-defined daily Anchor Action with occasional reminders.
- **Onboarding:** A frictionless, multi-screen process explaining the app's philosophy and requesting permissions.
- **Branding:** A minimalist, corporate Zen aesthetic named Koan, with a specific color palette (#A8D7F0, #D9F7EB, #FAFDFA, #3A3A3A), fonts (Söhne/Circular, Inter), and a simple dot+halo logo.
- **Authentication & Subscription:** Email/OAuth signup, Face ID support, and a 7-day free trial leading to a .99/month Stripe subscription.
- **Landing Page:** A calm, minimalist page serving as the app's entry point for new users.

The implementation so far has built out the authentication, a tab-based UI with home, nudges, insights, and settings screens, a branded landing page, and a functional backend.
</product_requirements>
